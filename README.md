### Hi, I'm Worakorn (First) 👋

Network security engineer at a system integrator in Bangkok. I also co-founded [Farmeral Technology](https://github.com/farmeral-technology), a small team building farm-management software for Thai livestock farms.

**Day job**

I've been working on firewall projects for financial-services customers since May 2025. That covers migrations, upgrades, cutovers with rollback plans, HA testing and TAC cases. Most of it happens in change windows at night.

- Firewalls: Cisco (FTD, FMC, ASA), Palo Alto (PAN-OS, Panorama, Strata Cloud Manager), Fortinet (FortiGate, FortiManager, FortiAnalyzer), Huawei USG
- Cloud / SASE: Prisma Access, Zscaler
- Tools: Wireshark, Nessus, WhatsUp Gold, Zabbix, VMware, EVE-NG, Linux

I write small tools to make that work less manual. Examples are Python scripts that convert and compare firewall configs during a migration, a traffic-report dashboard (React + NestJS), and Power BI reports.

**Farmeral**

We build Farmeter, an app for beef cattle and buffalo farms. It keeps animal records, health, breeding and costs in one place. My part is product, the frontend, and working with farms and research partners.

**Before this**

Computer Engineering at Kasetsart University (2021–2025). Side projects included Wi-Fi CSI indoor positioning (a research internship in Taiwan), a university activity app ([ZideQuest](https://github.com/ZideQuest)), and a few smart contracts.

**Learning now:** Palo Alto NGFW Engineer, CompTIA Security+ and PenTest+, Linux.
